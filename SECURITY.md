# Security

This is a deliberately buggy practice app. **Never deploy it anywhere real, and never put real
customer data in it.** The planted bugs are features of the sandbox, not vulnerabilities to report.

If you find a problem that could affect people *running* the sandbox (for example, something that
lets a container reach the host, or a dependency with a known vulnerability), please don't open a
public issue. Use GitHub's private
[security advisory](https://github.com/byshivam/arya-bank-sandbox/security/advisories/new) instead.
