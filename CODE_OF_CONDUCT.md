# Code of Conduct

This project is a place for people at every level, from their first API test to their hundredth
framework, to learn testing together. Be kind, be patient, and assume good intent.

**Expected:** helpful feedback on code and ideas, welcoming beginners, crediting others' work,
keeping challenge answers out of public issues so others can still play.

**Not acceptable:** harassment, insults or personal attacks, discriminatory jokes or language,
publishing anyone's private information, spam or self-promotion unrelated to testing.

Maintainers may edit or remove comments, issues and PRs that break these rules, and may block
people who keep breaking them.

Report problems to the maintainer through a private message on
[LinkedIn](https://www.linkedin.com/in/heyshivam) or by opening a
[private security advisory](https://github.com/byshivam/arya-bank-sandbox/security/advisories/new)
if it's sensitive. Reports are kept confidential.

This is based on the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
